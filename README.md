# منصة التشغيل المدرسية ذات العلامة البيضاء

عرض ويب تنفيذي عربي فاخر لمنظومة مدرسية مؤسسية متكاملة، صُممت لتعمل باسم كل مدرسة وهويتها دون اسم منتج ثابت.

## العرض المنشور

https://school-operating-system-showcase.mr-alzeerr.chatgpt.site

## ما يغطيه العرض

- مدرسة واحدة أو مجموعة مدارس أو عدة مجموعات وإدارات.
- شؤون الطلاب والتعليم والتقييم والجداول والحضور.
- الموارد البشرية والمالية والمشتريات والأصول والمرافق.
- الحماية والصحة والقانونية والحوكمة والجودة والامتثال.
- مركز قيادة وذكاء مؤسسي ولوحات متعددة المستويات.
- الهجرة الكاملة والتشغيل المتوازي والاستبدال المرحلي والتكامل.
- إضافات ذكاء اصطناعي اختيارية للتعليم والقوى العاملة.
- فصل واضح لتكاليف مزودي AI والـ Tokens والخوادم والأطراف الثالثة.
- معايير هندسية وأمنية وتجربة عربية RTL أصلية ومتجاوبة.

## التشغيل محلياً

```bash
npm install
npm run dev
```

## فحص الإنتاج

```bash
npm run build
npm run lint
```

> هذا المستودع يمثل العرض الترويجي والتنفيذي، وليس النظام المدرسي التشغيلي الكامل.
